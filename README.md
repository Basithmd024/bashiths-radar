# 📡 Basith's Radar — AI × PM Event Tracker & Digest Tool

A personal command center for an MGIT CSE builder tracking AI/PM events, hackathons, workshops across Hyderabad + Pan India, automated WhatsApp deadline alerts via Evolution API, and a daily Claude-filtered AI news digest.

---

## ⚡ Key Capabilities

1. **Event Radar & Tracker**
   - Scrapes & tracks events from Townscript (Hyderabad tech), Devfolio, Unstop, Dare2Compete, T-Hub, IIIT-Hyderabad, and MGIT Notice Board.
   - Real-time countdown pill color-coded by urgency (🔴 ≤3 days, 🟡 ≤7 days, 🟢 normal).
   - AI-generated one-line *"Why you should apply"* generated by Claude Sonnet.
   - Filter by Hackathon, Workshop, Summit, Conference, or Free-only.
   - Manual Event Add drawer for college notice board entries and offline events.

2. **AI Daily Digest Feed (Claude 3.5 Sonnet)**
   - Daily automated fetch from Anthropic, OpenAI Blog, TechCrunch AI, Hacker News, Product Hunt AI, and AI Snake Oil.
   - Ruthless filtering prompt: discards generic hype and only highlights actionable tools, breakthroughs, and architectural shifts.
   - Priority ratings (1–5), color-coded tag pills (`Breaking`, `Launch`, `Update`, `Research`), and 1-click dismiss.

3. **WhatsApp Deadline Reminders (Evolution API)**
   - Automated 4-tier schedule: **7 days before**, **3 days before**, **1 day before**, and **Morning of Event**.
   - Sent via self-hosted **Evolution API** or Twilio WhatsApp sandbox.
   - Formatted templates with direct apply links and countdowns.

4. **1-Click Google Calendar Sync**
   - OAuth 2.0 flow creating 2 automated calendar events:
     - 📝 **Application Deadline** (with 1-day advance notification)
     - 🎯 **Event Date** (with 2-hour advance reminder)

---

## 🛠 Tech Stack

- **Frontend**: Next.js 14/15/16 (App Router), Tailwind CSS v4, Lucide Icons, Sonner Toaster
- **Backend**: Next.js API Routes (Node.js)
- **Database**: Supabase PostgreSQL (with Row Level Security & Indexes)
- **Auth**: Supabase Auth (Magic Link Email & Google OAuth)
- **AI Intelligence**: Anthropic Claude SDK (`claude-sonnet-4-5`)
- **WhatsApp Engine**: Evolution API (Open Source WhatsApp gateway)
- **Calendar**: Google Calendar API v3
- **Automation / Cron**: Vercel Cron (`vercel.json`)

## 🚀 Quickstart & Local Setup

### 1. Clone & Install Dependencies

```bash
cd /Users/basith/.gemini/antigravity-ide/scratch/bashiths-radar
npm install
```

### 2. Configure Environment Variables

Copy `.env.local.example` to `.env.local`:

```bash
cp .env.local.example .env.local
```

Fill in your API keys:
- `NEXT_PUBLIC_SUPABASE_URL` & `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ANTHROPIC_API_KEY`
- `EVOLUTION_API_URL` & `EVOLUTION_API_KEY` (or Twilio)
- `GOOGLE_CLIENT_ID` & `GOOGLE_CLIENT_SECRET`
- `CRON_SECRET`

### 3. Setup Supabase Database

In your [Supabase Dashboard](https://supabase.com):
1. Go to **SQL Editor** → **New Query**
2. Paste and run [`supabase/schema.sql`](supabase/schema.sql)
3. Paste and run [`supabase/seed.sql`](supabase/seed.sql)

### 4. Run Development Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

## ⏰ Cron Jobs & Endpoints

Configured in `vercel.json`:
- `POST /api/cron/scrape-events` — Runs at `23:00 UTC` (`4:30 AM IST`)
- `POST /api/cron/fetch-digest` — Runs at `23:30 UTC` (`5:00 AM IST`)
- `POST /api/cron/send-reminders` — Runs hourly (`0 * * * *`)

To trigger manually in development:
```bash
curl -X POST http://localhost:3000/api/cron/fetch-digest?secret=YOUR_CRON_SECRET
```
